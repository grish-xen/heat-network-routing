# Общие данные

- `competition-corrected.geojson` — актуальный конкурсный набор; алгоритм не должен зависеть от его конкретных координат, ID и числа объектов.
- `synthetic/two-consumers/input.geojson` — небольшой самостоятельный вход.
- `synthetic/two-consumers/metric-case.json` — точный граф в EPSG:32637 и ожидаемые расчётные значения.
- `synthetic/two-consumers/expected.geojson` — согласованный результат этого кандидата в EPSG:4326.
- `api/` — ответы для разработки интерфейса на заглушках.

Подробности и ожидаемые суммы — [план проверок](../docs/TEST_CASES.md). Пример не является утверждением глобальной оптимальности выбранного маршрута.
