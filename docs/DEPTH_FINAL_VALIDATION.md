## Углы специальных пересечений

Раньше `DefaultSpatialValidator` измерял угол ломаной по её крайним точкам и пропускал Polygon/MultiPolygon/MultiLineString. Теперь каждый фактически пересечённый отрезок линии проверяется отдельно. Для полигона используется местная граница в точке входа по направлению ребра; каждое повторное вхождение после отверстия или промежутка проверяется. Геометрия между отдельными компонентами не выдумывается. На вершине границы учитываются оба прилегающих отрезка; повторяющиеся координаты не создают направление.

Перед проверкой восстанавливается прямой спецпроход, разделённый техническими узлами из-за наложений. Угловой допуск 1e−9 градуса отделён от линейного допуска 0,001 м. Ошибка содержит SPECIAL_PASS_VIOLATION, inputObjectId ограничения и segmentId участка. Минимальный угол берётся из общего каталога.

`SpecialCrossingAngleTest`: 14 сценариев × TWO_D/DEPTH, каждый для дороги и трамвая. Ломаные, несколько пересечений и компонентов, полигон с отверстием, смена направления входа, ровно 45° и 44,9995°, разделённый спецпроход; координаты сдвинуты к масштабу UTM. До исправления 20 из 28 проверок падали. В PR #29 изменялся только модуль 2.

После разрешения владельца проекта исправлен и модуль 3: `SpecialPasses.checkAngle` больше не накладывает ограничение на угол выхода из полигона. `PolygonEntryCalculationTest` проверяет настоящий калькулятор с независимым валидатором: допустимый вход с острым выходом, обратное направление, несколько компонентов, отверстие, линейное препятствие и ровно 45°. Шесть сценариев в TWO_D/DEPTH, каждый для дороги и трамвая. Типы, стоимость и построитель профиля не изменены.

## Повторение

Полный совместный `mvn verify` на Java 11 после исправления калькулятора: 335 тестов, без ошибок и пропусков (в PR #29 было 323). `python scripts/check_repository.py` прошёл. Ветка `fix/calculation-polygon-entry` включает PR #29 и проверяет оба модуля вместе.

mvn -f backend/pom.xml verify
python scripts/check_repository.py
python scripts/smoke_api.py --mode depth --input test-data/synthetic/depth/gas-below/input.geojson --require-full-connection
python scripts/smoke_api.py --mode 2d --input test-data/competition-corrected.geojson --require-full-connection
