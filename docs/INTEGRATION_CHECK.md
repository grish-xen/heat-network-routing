## Найденный и исправленный сбой модуля 1

Первый конкурсный запуск завершился INTERNAL_ERROR: Windows вернула AccessDeniedException при замене `.json.tmp` на файл статуса в FileJobStore.save. Сериализация доступа внутри сервера уже существовала; источник внешней блокировки не установлен.

Добавлен ограниченный повтор публикации при AccessDeniedException без предварительного удаления старого файла. Пять тестов проверяют временный и постоянный отказ, замену без поддержки атомарного перемещения, другие ошибки I/O и прерывание. Повторный конкурсный запуск завершился успешно. Это не доказательство отсутствия любых будущих файловых блокировок.

Проверки: backend `mvn verify` — 175 тестов, 0 ошибок; frontend `npm run build` — успешно (предупреждение о размере JS chunk); `python scripts/check_repository.py` — успешно.
