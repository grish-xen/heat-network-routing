# Проверка стартового репозитория — 19.09.2026

Готов как общая база параллельной разработки: реализован запуск приложения, закреплены Java-контракты и API-спецификация, добавлены справочники и согласованные тестовые данные. Реализации расчётных интерфейсов и пользовательского приложения предстоят команде.

## Выполнено

- Сборка Maven на JDK 11 с получением исполняемого JAR; четыре теста проходят без ошибок. Проверены запуск HTTP-сервера, health, генерация Swagger, сохранение числовых/строковых ID и больших числовых ID.
- Проверены числовые строки таблицы ДУ, цены камер и коэффициенты специальных проходов против актуального DOCX, а также контрольная сумма документа-источника.
- Проверены обязательные поля конкурсного набора и согласованность небольшого примера: связи, расходы, ДУ, длины, стоимость, идентификаторы и итоговый показатель.
- OpenAPI 3.0.3 проверен `openapi-spec-validator 0.7.2`; три примера HTTP-ответов соответствуют своим схемам.
- Конфигурация запуска проверена командой `docker-compose 1.29.2 config --quiet`.
- В GitHub Actions добавлены сборка/тесты, проверки общих файлов, OpenAPI и конфигурации Compose. Запуск Actions произойдёт после загрузки в GitHub.

## Практические границы проверки

Docker Engine в этой среде отсутствует: контейнеры и полный запуск на Ubuntu ещё не проверялись. Frontend пока представлен инструкцией и примерами ответов; алгоритмы, файловый API, БД, очередь, лимиты памяти/размеров файлов и 50 пользователей не реализованы и не проверены.

Синтетический пример проверяет расчёт заданной схемы, но не доказывает её оптимальность. Проверка структуры конкурсного набора не заменяет проверку всей геометрии и нормативных ограничений будущим SpatialValidator.
