## Подтверждение / замечания

| ID | Допущение | Отзыв участника 2 | Последствие |
| --- | --- | --- | --- |
| P1 | Глубина корня и потребителя = 3,0 м | **Подтверждаю для первого режима.** У входных точек нет собственной глубины; это упрощает поиск. При коротком пути без места для перехода может исключить допустимый маршрут — это ограничение выбранной стратегии, не ошибка |
| P2 | В камере совпадает глубина **верха** новых участков | **Подтверждаю с оговоркой.** При разных ДУ оси/низ отличаются — это упрощённая модель камеры. Для планового поиска 2D это допустимо; при детальной модели камеры (будущая работа) потребуется уточнение |
| P3 | Спецпроход: постоянная глубина в пределах протяжённости, подъём/спуск снаружи | **Подтверждаю как консервативное толкование.** Для прямого прохода это безопасно. При наложении нескольких проходов или необходимости сохранить изменённую глубину между близкими препятствиями возможны дополнительные технические узлы — это не ошибка, а ограничение первого режима |
| P4 | Новые трассы не пересекаются вне общего узла даже при разных глубинах | **Подтверждаю для первого режима.** Многослойные пересечения новых трасс требуют отдельных правил; их поиск — расширение, не обязательное для начального DEPTH |
