## Найдена блокировка конкурсного примера

Полный строгий браузерный сценарий в CI пока красный: газовый и разветвлённый примеры проходят, конкурсный backend-расчёт завершается `SUCCEEDED`, но frontend показывает «Не удалось загрузить данные глубинной модели» вместо 3D. Запросы карты возвращают 200. Это отдельная проблема от локальных тайм-аутов расчёта.

`loadMapFeatures` применяет лимит 2000 к частям всех входных геометрий, включая стороны полигонов. `toSceneCommunications` использует только линейные газопроводы, кабели и существующие теплосети. [Диагностический прогон](https://github.com/grish-xen/heat-network-routing/actions/runs/36569649850) на `c51f5b6` подтвердил для фактического bbox:

- 144 входных объекта, 5938 частей геометрии; загрузчик выдаёт «Превышен предел объектов для глубинной сцены: 2000».
- Для выбранного пути преобразователи дают **3 части трубы + 68 частей коммуникаций = 71**, существенно ниже бюджета 2000.
- При переключении на профиль остаётся та же ошибка (`profileBlockedBySameError=true`).

В полном входе 5464 части относятся к ограничениям `oks`. Неиспользуемая в 3D геометрия исчерпывает бюджет до построения сцены. `ResultWorkspace` также объединяет ошибку входных коммуникаций с ошибкой данных профиля. Все числа здесь — диагностические результаты конкретного примера, не константы алгоритма.

Участнику 4: сохранить общий лимит фактических частей сцены, отделить его от ограничения объёма загружаемых данных; не расходовать GPU-бюджет на объекты, которые не рисуются в 3D. Ошибка/лимит коммуникаций не должны блокировать профиль при успешно загруженной расчётной трассе. Превышение отдельного лимита загрузки должно давать точное сообщение, а не предлагать бессмысленный повтор.

Критерии: конкурсный файл открывает профиль для всех 17 потребителей и 3D для пути в пределах бюджета; случай 1200 + 1200 по-прежнему не создаёт сцену, экспорт доступен. Синтетический вход с большим числом вершин зданий и короткой коммуникацией не должен ошибочно исчерпывать бюджет 3D. Ограничения на объём загрузки сохраняются отдельно.
